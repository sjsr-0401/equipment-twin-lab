### 소프트웨어 아키텍처 설명

이번 작업은 공정 계산 계층이 아니라 Unity 표시 계층만 바꿨다.

```text
Core/CLI timeline
    -> MolyAldVisualStateMapper
    -> MolyAldVisualState
    -> MolyAldPrimitiveVisualizer labels/panels/flow bar
```

`MolyAldVisualState`에는 `CycleCount`를 추가했다. 이유는 화면에 `Cycle 1/1` 같은 값을 표시할 때 visualizer가 cycle 개수를 하드코딩하지 않게 하기 위해서다.

### 유지보수 포인트

- 화면에 뭘 더 추가하고 싶으면 먼저 `MolyAldPrimitiveVisualizer.cs`를 본다.
- 공정 데이터에서 화면 표시값으로 바꾸는 규칙은 `MolyAldVisualStateMapper.cs`에 둔다.
- 실제 공정 로직은 Unity에 넣지 않는다.
- 이미지가 너무 복잡해지면 새로운 기능을 추가하기보다 label 수를 줄여야 한다.
